视频里的小地图方位与视角方向，实时叠在你的游戏画面上

第一次使用

按这三步走，基本不会踩坑

1游戏内「图像 → 显示模式」改成 窗口化 或 无边框；独占全屏下系统不允许任何浮窗盖上去。
2在「方位标定」里框选视频小地图，再把红圈拖到你自己的小地图上。
3回到游戏，用快捷键暂停 / 快进。默认 Alt+空格 暂停播放。

方位标定

红箭头是视频里角色的行进方向，绿弧是镜头视角方向，两者独立识别、互不干扰。

显示与标定

标定结果按视频记住，换片不用重新框

标记大小叠加层上红圈与绿弧的直径 110

框选要在浮窗里做：点了会把浮窗叫起来，拖金色圆环套住视频里的小地图，滚轮调大小。
转场 / 特写 / 对话时画面里没有小地图，箭头会自动收起，不是故障。

两个方向为什么要分开

站着原地转镜头时，角色朝向和行进方向可以差 180°

红青色玩家三角指向的方向 = 角色正在往哪走，来自小地图中央的箭头。
绿半透明白色扇形（恒定 90° 张角）的中轴 = 镜头看过去的方向，来自视野指示扇形。

浮窗

控制置顶、穿透、透明度与播放行为；改完立刻生效，会自动记住。

窗口行为

游戏里也能用全局快捷键随时切换

显示与声音

不透明度低一些更不挡视野

不透明度整个浮窗的可见程度 100%
音量视频播放音量，与系统音量独立 100%

想压在原神上面：游戏内「显示模式」请选 窗口化 或 无边框。独占全屏下任何外部浮窗都无法被系统合成上去。

全局快捷键

点键位后按下新组合，也可以只按一个键，或直接按鼠标侧键。

键位 游戏全屏时同样生效

带 Alt / Ctrl 的组合是独占的，单键走被动监听

单键（如 F9、J）走系统钩子被动监听：不占用、不拦截按键，但因此游戏里同一个键也会照常生效，建议挑不常用的键。 带 Alt / Ctrl 的组合则是独占的，按下去别的程序收不到。
