# 原神跟跑助手

一个可以 **压在原神窗口之上** 的 B 站视频悬浮窗：边跑地图边看攻略，按一下快捷键就能暂停视频，不用 alt+tab 切出去。

## 下载与安装

**最新版下载：** https://github.com/FinalLawer/test1/releases/latest

发布包有两种，功能完全一样，按习惯选一个：

| 版本 | 直接下载 | 适合 | 设置保存在 |
| --- | --- | --- | --- |
| **zip 绿色版** | [GenshinRouteBuddy-0.2.4-win-x64.zip](https://github.com/FinalLawer/test1/releases/download/v0.2.4/GenshinRouteBuddy-0.2.4-win-x64.zip) | 解压到任意文件夹双击即用，不写注册表，整个文件夹可以拷走 / 放 U 盘 | 程序目录里的 `data\` |
| **安装版** | [GenshinRouteBuddy-0.2.4-Setup.exe](https://github.com/FinalLawer/test1/releases/download/v0.2.4/GenshinRouteBuddy-0.2.4-Setup.exe) | 想要开始菜单 / 桌面快捷方式、卸载器、开机自启 | `%APPDATA%\原神跟跑助手\` |

下载包旁边附有 `SHA256SUMS.txt`，需要核对文件完整性时可以比一下哈希。

- **第一次双击会弹一次 UAC 申请管理员权限，点「是」**：全局快捷键要在以管理员权限运行的游戏里也生效，这是 Windows 的限制。
- 安装版有自定义安装页，可以选安装目录，并按需勾选「从旧绿色版迁移数据」（把旧 `data\` 里的设置和小地图标定复制过来）、「同时迁移 B 站登录态」、「开机自动启动」。不勾选也没关系，重新登录一次即可。
- 卸载安装版**不会**删掉设置和标定，重装可以接着用。
- 绿色版想搬走设置，把 `data\` 一起拷走就行。

## 开始使用

1. 游戏内 → 设置 → 图像 → 显示模式，选 **窗口化** 或 **无边框**。
   不要选「独占全屏」：它会绕过 Windows 桌面合成，任何外部浮窗都盖不上去，这是系统限制。
2. 打开启动器，粘贴 B 站视频链接（BV 号、av 号、完整链接、`b23.tv` 短链、带 `?p=3` 的分 P 链接都支持）。
3. 浮窗出现后可以拖动位置、拖角缩放；标题栏点「登录」扫码登录 B 站即可看高清。

## 功能

- **永远置顶**：压在游戏窗口之上，层级被抢会自动夺回；显示时不会把游戏切到后台
- **全局快捷键**：游戏全屏、鼠标在游戏里也生效，默认 `Alt+空格` 暂停 / 播放
- **B 站网页版播放器**：自动点「网页全屏」铺满浮窗，登录后 1080P / 4K / 大会员画质正常
- **纯净模式**：自动隐藏顶栏、右侧推荐、评论区、广告
- **扫码登录**：标题栏「登录」调起扫码窗口，成功后自动关窗并按高清重载，只需登录一次
- **分 P 切换**：自动读取分 P 列表，下拉选择或快捷键切换，下拉框会标出当前 P
- **上次看到**：下次启动可以接着播上次看的视频
- **鼠标穿透**：开启后点击直接落到游戏里，浮窗只做显示
- **不透明度 / 音量 / 倍速 / 拖动进度 / 拖角缩放**，设置与窗口位置自动记忆
- **小地图方位标记**：见下文

## 快捷键

| 功能 | 默认键 |
| --- | --- |
| 播放 / 暂停 | `Alt+空格` |
| 后退 5 秒 | `Alt+←` |
| 前进 5 秒 | `Alt+→` |
| 上一分 P | `Alt+↑` |
| 下一分 P | `Alt+↓` |
| 隐藏 / 显示浮窗 | `Alt+H` |
| 鼠标穿透 开 / 关 | `Alt+L` |
| 半透明 开 / 关 | `Alt+O` |

全部可在 ⚙ 设置里点击对应的键位重新录制（需要至少一个修饰键，F1–F12 可单独使用）。

**鼠标侧键**：点击任意键位后直接按鼠标侧键，即可把「后退 / 前进」侧键绑上去，录完显示为 `鼠标侧键 ◀` / `鼠标侧键 ▶`。侧键是系统级监听，游戏全屏、焦点在游戏里时照样触发；浏览器里侧键的前进后退也不受影响。

> 如果侧键同时被鼠标驱动软件（罗技 G HUB、雷蛇等）绑定了宏，可能会被驱动先截走，触发不到；把驱动里的绑定清掉即可。

## 登录与画质

B 站现在很多视频必须登录才能完整观看，未登录时播放器只给预览或标清：

1. 点标题栏右上角的 **「登录」**（登录后变成一个绿点），弹出 B 站扫码窗口
2. 手机 B 站扫一扫，登录成功窗口会自动关闭
3. 浮窗自动重载当前视频，画质上限随之提升

之后每次启动都是登录状态。如果登录后仍然提示受限（会员专享、付费内容、充电专属视频等），那属于账号权限问题。

> 网页版播放器的首屏会比嵌入播放器慢一两秒，换来的是完整画质。

## 小地图方位标记

叠加层会在屏幕上画两个标记：**红色箭头**是视频里博主正在行进的世界方位，**绿色圆弧**是镜头 / 视野朝向。两者互相独立，站着转视角时方向差很多是正常的。标记画在屏幕坐标系上，所以不管你自己的小地图是固定北朝上还是随角色旋转都能用。

前提只有一个：**视频里的小地图必须固定北朝上**。如果是随角色旋转的，中央箭头恒朝上，世界方位信息根本不存在。

### 标定

- ⚙ → ① 框选视频里的小地图 → 拖动圆环对准箭头支点 → 滚轮调大小 → 完成
- 同一个视频里，平时是游戏原生的小地图，讲到路线时常换成剪辑放大的地图贴片，位置和大小完全不同，所以**可以框多处**（位置重合则替换，最多 4 处），每帧自动挑最可信的一块
- 标定结果**按视频记住**，换视频不用重框
- 转场、特写、对话时画面里没有小地图，标记会自动收起

### 一个必须接受的局限

这是**够用级**方案，不是导航级：地形干扰、传送锚点图标、角色朝向 ≠ 行进方向（回头打怪时朝向立刻反向），都会让结果偏离。实测在正常游玩画面上误差约 ±10~20°，大方向可用，精确定位不行。

## 已知限制

- 独占全屏下无法覆盖（请改成窗口化 / 无边框）
- 部分游戏使用 Raw Input 独占键盘，若快捷键失效，在设置里换成别的组合键
- 必须登录才有 1080P / 4K，未登录时 B 站自己只放预览或标清
- 网页版首屏比嵌入播放器慢一两秒
